# ADR 0054: governed presentations and server scan sessions

Accepted for local implementation, 2026-10-14. V4 remains incomplete.

Host resolves all nineteen primitive identifier categories through their actual owners. Controlled label templates, issuances, copies, aliases and print attempts reference those subjects without creating stock or authentication authority. ZXing.Net0.16.11 renders actual Code128/QR/DataMatrix SVG symbols in the existing Engineering content store. Unsupported encodings fail closed. Print acknowledgment, physical attachment and recorded subject identity remain separate facts.

Quality owns explicit independently approved policy adoptions. Never-effective proposals do not enable controls. Withdrawn, ambiguous or unavailable previously effective adoption fails closed; consumers cannot fall back to uncontrolled behavior. Definitions, selectors, process/risk basis and mixed source permissions are checked in the consuming transaction and before retry.

Kernel provides a generic transaction participant without operational scan models. Host resolves that participant lazily after service construction. A server session binds actual provider authentication, current workstation/operator, operation, machine, source versions, approved policy and channel generation. Generation compare-and-swap, finite expiry and current source validation reject delayed A requests after B becomes current. An explicit governed trusted-terminal policy may identify a separate actual worker; a current-authenticated-worker policy requires that worker to be the authenticated person. Codes never authenticate either.

StartOperation and ReportProduction carry the session explicitly. Their ordinary owner checks remain authoritative. Accepted scan evidence is immutable and linked in the same transaction to its actual succeeded audit and event IDs. An optional audit owning resource/context fingerprint preserves null legacy hash bytes. Historical acceptance reads use their saved selections rather than later staging and recheck recorded/current mixed source permissions. Generated label content cannot be laundered through file upload/use/download after its owning source access is withdrawn.

The custom-role upgrade case preserves an organization's same-name role metadata, grants/scopes and assignments. Separate narrow authorities grant no product-release permission through shipping roles.
